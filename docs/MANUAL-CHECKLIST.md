# 人工验收清单 / Manual acceptance checklist

浏览器不能在本沙箱里启动（进程间 IPC 被拒），所以「点击 → 重渲染」这一层请在真机上用
这份清单过一遍。全部是可见行为，不需要开发者工具。

Run through this list in a real browser; every item is observable behaviour.

## 1. 首屏
- [ ] 深色背景 + 蓝紫霓虹光晕，卡片有玻璃质感，无明显廉价模板感。
- [ ] 首页显示 `QKBEST`、身份（中国大学生 / University Student in China）、性格（内敛）、简介。
- [ ] 时钟每秒跳动，日期为当前本地日期；右上角显示时区。

## 2. 语言
- [ ] 点右上角 `EN` → 导航（Home / Interests / Projects / Quick Links / Toolkit / Social）、
      标题、按钮、空状态、校验提示全部变英文，`<html lang>` 也变 `en`。
- [ ] 再点 `中文` 全部切回中文。刷新后保持上次选择。

## 3. 主题
- [ ] 点 ☀ → 切到浅色模式，文字对比度正常，卡片仍可读。
- [ ] 刷新后仍是浅色；点 ☾ 切回深色。

## 4. 兴趣 + 项目
- [ ] 兴趣页/首页都有 4 张卡片：无畏契约、人工智能、篮球、电影，各有渐变色图标与标签。
- [ ] 项目区每张卡右上角有 `示例 / Sample` 角标。
- [ ] 搜索框输入 `react` → 只剩匹配卡片；输入不存在的词 → 出现空状态 + 「清除筛选」按钮。
- [ ] 点分类 chip（网页 / AI / 工具 / 游戏 / 学习）→ 列表正确收敛，再点「全部」恢复。

## 5. 快捷链接
- [ ] 「新增链接」弹窗：标题留空 → 报错；网址填 `javascript:alert(1)` 或 `abc` → 报错。
- [ ] 填 `example.com` → 保存成功，列表里显示 `example.com`（已自动补 https）。
- [ ] 重复添加同一网址 → 提示已存在。
- [ ] 编辑某条 → 弹窗预填 → 改完保存，列表更新且不产生重复行。
- [ ] 删除某条 → 确认后消失。刷新页面，上面的增删改都还在。

## 6. 番茄钟
- [ ] 点「开始」→ 倒计时走动、进度环前进。
- [ ] 点「暂停」→ 时间冻结、按钮变「继续」；点「继续」→ 接着走。
- [ ] 点「重置」→ 回到该模式的完整时长。
- [ ] 时长输入 0 或 999 → 点「应用时长」提示取值范围；输入 1 → 应用后显示 `01:00`。
- [ ] 让 1 分钟的专注跑完 → 听到提示音、弹出提示、自动切到「短休息」、轮次 +1。

## 7. 便签 / 待办
- [ ] 便签：空内容点新建 → 报错；输入文字 → 保存；编辑 → 保存；删除 → 消失并出现空状态。
- [ ] 待办：新增两条 → 勾选一条 → 计数从 2 变 1，完成项有删除线。
- [ ] 筛选「未完成 / 已完成 / 全部」结果正确；「清除已完成」生效；删除单条生效。
- [ ] 刷新后便签与待办都还在。

## 8. 社交 + 兜底
- [ ] 社交区 4 个虚位（GitHub / B 站 / 邮箱 / 其他主页）显示「待填写」，都是虚线不可点击，
      页面明确写出「暂无已公开的社交账号」——没有任何编造的账号。
- [ ] 页脚「清空本地数据」→ 确认后便签/待办/链接/主题全部恢复默认。

## 9. 响应式
- [ ] 手机宽度（<900px）导航折叠成 ☰，展开可点，跳转后自动收起。
- [ ] 手机宽度无横向滚动条；平板 / 桌面布局正常。
